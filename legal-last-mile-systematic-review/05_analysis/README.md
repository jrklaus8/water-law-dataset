# 05_analysis — the evidence map, the effect sizes and the checks on them

| Folder | What it holds |
|---|---|
| `descriptive/` | `evidence_map.csv` — one row per study classifying its design, mechanism family, outcome and certainty (`EVIDENCE_MAP_README.md` explains the columns); data-quality, sparse-record and exclusion-basis audits; proposals for controlled vocabularies and the researcher's overrides of them |
| `effect_sizes/` | `effect_sizes.csv` — the effect-size rows and which synthesis family each belongs to (or that it is a reasoned non-fit); the **31-study source verification dossier** (`SWIM_31_SOURCE_VERIFICATION_DOSSIER.md`: stored value next to the verbatim passage of the PDF, every verification box blank for the author), `SWIM_DIRECTION_CODING_*.csv` (the two-column direction coding), `EFFECT_ROW_NUMBER_CHECK_*.md` (what the PDFs print for six stored numbers; three corrections proposed, none applied) |
| `sensitivity/` | The scenarios that remove or recode doubtful studies and re-test the pre-stated conclusions (`SENSITIVITY_ANALYSIS_*.md`). The current results are regenerated by `code/analysis/sensitivity_analysis.py` |
| `meta_analysis/`, `heterogeneity/`, `publication_bias/` | **Empty by design.** No family could be pooled, so no meta-analysis, heterogeneity or publication-bias analysis was run. The R templates for them are in `../08_code/R/` |

**Direction coding, in one paragraph.** For each synthesis study there are two columns: the *raw sign* of the reported estimate, and the *substantive direction for households* (Favourable, Unfavourable, Null or Mixed), derived as sign × the outcome's polarity (a higher tariff is worse, a higher coverage is better) × the exposure's orientation. Both are shown so a reader can disagree with one without the other.

**Who checked it:** the AI built every file here. The researcher ruled on which studies stay in the syntheses; the author has **not yet confirmed any study's direction coding** (item `A30`).
