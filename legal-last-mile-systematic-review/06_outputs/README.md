# 06_outputs — what a reader is meant to read

| File or folder | What it is | How it was made |
|---|---|---|
| `EVIDENCE_ATLAS_INTERACTIVE.html` | The interactive atlas: results, methodology, flow, evidence map, appraisal, direction of association, robustness, gaps, full text lists. Open it in a browser. Live copy: https://jrklaus8.github.io/water-law-dataset/atlas/ | Generated from the databases by `code/analysis/build_evidence_atlas.py`; a test checks the page equals the generator's output |
| `EXECUTIVE_SUMMARY_*.docx` | Findings, robustness and open decisions in short form | Generated by `code/analysis/build_executive_summary.py` |
| `PRELIMINARY_RESULTS_REPORT_*.md/.html/.docx` | The longer preliminary report | Generated by `code/analysis/build_preliminary_report.py` |
| `prisma/` | The PRISMA 2020 flow and the checklist, with each item's location | Flow generated from the databases; checklist completed by the AI |
| `figures/` | Five SVG figures used in the report | `code/analysis/build_figures.py` |
| `supplementary/` | The three SWiM syntheses (`family_A_…`, `family_B_…`, `family_C_…`), the pooling-feasibility judgment, and older preliminary results kept as dated snapshots | AI drafted |
| `slides/` | A slide summary produced by the researcher with a different AI tool; kept unaltered, and where it differs from the report the report is right | See `slides/README.md` |
| `tables/` | Empty placeholder | — |

**Everything here is preliminary.** Figures in dated files are the figures true on that date; `../00_admin/CURRENT_FIGURES.md` is current.
