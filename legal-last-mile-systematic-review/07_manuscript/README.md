# 07_manuscript — drafts, not a submission

`draft/` holds the manuscript draft (`MANUSCRIPT_DRAFT_*.md/.docx`), supporting texts and the outline. The draft is **generated** from the databases by `code/analysis/build_manuscript_draft.py` and `build_manuscript_pieces.py`, so its numbers match the data at the date in the file name; it is not a finished or submitted paper, and it states the AI-assisted and partly-verified status of the work.

`response_to_reviewers/` and `revisions/` are empty placeholders for a future submission.

The publication plan (target journals, what must be done first) is `../PUBLICATION_PLAN.md`.
