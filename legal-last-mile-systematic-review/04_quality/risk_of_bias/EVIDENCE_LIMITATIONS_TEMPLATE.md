Per `RISK_OF_BIAS.md` §3: once every included study has been individually
appraised (`04_quality/appraisal_forms/APPRAISAL_FORM.md`), write **one**
short narrative here summarizing limitations of the evidence base **as a
whole** — not a per-study repeat of each individual appraisal, and not a
simple tally of ratings. This feeds directly into the Discussion/
Limitations sections of `PUBLICATION_PLAN.md`.

Copy this template to a dated file in this same folder (e.g.
`2027-XX-XX_evidence_limitations.md`) once appraisal is actually
complete — this file itself stays a blank template, never filled in
directly, so the shell survives being copied for a future re-appraisal
round.
