# Where to Download the Data

The complete dataset (CSV + Excel, base + jurimetric-coded) is available at four repositories:

---

## Files Available

| File | Description | Size |
|------|-------------|------|
| `water_law_global.csv` | All 83,596 cases, unified schema | ~64 MB |
| `water_law_global.xlsx` | Same, Excel with per-country sheets + summary | ~39 MB |
| `water_law_global_coded.csv` | All cases with 7 jurimetric variables | ~66 MB |
| `water_law_global_coded.xlsx` | Same, Excel format | ~23 MB |

---

## Download Links

### Zenodo *(primary archive)*
**DOI:** `10.5281/zenodo.19836413`  
**URL:** https://doi.org/10.5281/zenodo.19836413  
Version-controlled, citable. Best for academic citation. Current release: **v0.3.0**.

### Harvard Dataverse
**DOI:** `10.7910/DVN/C9PEFS`  
**URL:** https://dataverse.harvard.edu/dataset.xhtml?persistentId=doi:10.7910/DVN/C9PEFS  
Hosted by the Harvard Institute for Quantitative Social Science.

### DANS Data Station SSH
**DOI:** `10.17026/SS/RVDBUF`  
**URL:** https://ssh.datastations.nl/dataset.xhtml?persistentId=doi:10.17026/SS/RVDBUF  
Dutch national archive for Social Sciences and Humanities data.

### OSF (Open Science Framework)
**URL:** https://osf.io/admrq  
Open, no login required.
